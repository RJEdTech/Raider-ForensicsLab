# Raider ForensicsLab

Interactive investigations for Regis Jesuit Forensic Science: crime scenes, fingerprints, toxicology, blood spatter, DNA, forensic anthropology, digital forensics and cybercrime, plus cybersecurity exploration tools for any class. It is a companion to [Raider ChemLab](https://rjedtech.github.io/Raider-ChemLab/), [Raider BioLab](https://rjedtech.github.io/Raider-BioLab/) and [Raider PhysLab](https://rjedtech.github.io/Raider-PhysLab/) and runs on the same engine.

**Live site:** https://rjedtech.github.io/Raider-ForensicsLab/

Every tool is clinical, defensive and fictional: diagrams and data instead of graphic images, investigations instead of attacks, and invented people, places and organizations. Everything runs in the browser, with no logins and no data collection.

## Pathways
- **Forensic Science** (in the order RJ's course teaches it): crime scene → fingerprinting → poisons and toxicology (toxicology, spot tests, chromatography, spectroscopy) → time of death → handwriting and trace evidence (hair and fiber) → forensic anthropology → blood spatter and DNA → digital evidence (hashing, file signatures, metadata, deleted files) → cybercrime (passwords, phishing, ciphers and steganography, logs) → a digital case file capstone.
- **Explore cybersecurity** (any class, including AP CSP and the AP cyber courses): binary, how the internet moves data, public-key cryptography, risk, firewalls and logs, alongside the digital forensics tools.

Link straight to a tool with `#<name>` (e.g. `#bloodspatter`, `#casefile`) or to a pathway with `#path-forensic` / `#path-cyber`.

## Files
- `index.html`, `biolab.css`, `engine.js` (shared lab bench), `chemdata.js` (chemistry helpers), `courses.js` (sections and pathways), `sims/*.js` (one file per tool), `ENGINE.md` (authoring guide).
